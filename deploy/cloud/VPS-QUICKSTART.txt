A) From your PC — copy weights:

C) On the VPS:
   curl -fsSL https://raw.githubusercontent.com/king0079z/car-track-pro/main/deploy/cloud/bootstrap-vps.sh -o /root/bootstrap-vps.sh
   chmod +x /root/bootstrap-vps.sh
   sudo bash /root/bootstrap-vps.sh cartrackpro.duckdns.org YOUR_DUCKDNS_TOKEN YOUR_CAMERA_PASSWORD

   (If curl 404, clone the repo instead:)

   cd /opt/cartrack/deploy/cloud
   cp /root/best.pt data/models/
   cp env.cartrackpro.template .env.cloud
   sudo bash setup-oracle.sh cartrackpro.duckdns.org YOUR_DUCKDNS_TOKEN


VERIFY
------
  curl https://cartrackpro.duckdns.org/api/health

  cd /opt/cartrack/deploy/cloud
  docker compose -f docker-compose.oracle.yml logs -f backend

  Look for:
    - "Dahua cloud camera configured"
    - P2P "Ready to connect"
    - "Camera provisioner: started 1/1 enabled camera(s)"


TROUBLESHOOTING
---------------
| Problem | Fix |
|---------|-----|
| SSH refused | Hetzner firewall: allow 22. Wait 1 min after create. |
| HTTPS not loading | Wait 60s for Let's Encrypt. Check ports 80/443 open. |
| P2P timeout | Confirm DAHUA_DEVICE_SERIAL in .env.cloud matches DMSS → Device info. |
| Wrong camera password | Edit /opt/cartrack/deploy/cloud/.env.cloud then: docker compose -f docker-compose.oracle.yml up -d --build |
| ANPR no weights | scp best.pt to /root/best.pt, re-run bootstrap |
| Site loads, no live feed | Settings → Cameras → hero-a1 → Connect, or check backend logs |
